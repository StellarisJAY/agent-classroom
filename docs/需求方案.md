# 智能体课堂系统 · 需求方案

> 版本 v1.0（已确认）

## 1. 项目概述

智能体课堂系统：用户提出需要学习的知识点并上传参考文档，智能体自动生成可互动的教学课程。

课程由多个环节按序排列组成，环节有三种形式：**Slide 讲解**、**测试题**、**互动演示**。

## 2. 技术栈

| 层 | 选型 |
|---|---|
| 后端 | Go + gin |
| 数据库 | PostgreSQL |
| 前端 | Vue 3 + Vite + Pinia + Vue Router + TypeScript |
| 公式渲染 | KaTeX |
| 沙箱 | iframe（HTML5）|
| 生成进度推送 | SSE |

## 3. 数据模型

```
课程 Course
 ├─ 标题、知识点描述、参考文档（纯文本提取结果）
 ├─ 大纲 Outline（环节列表，有序）
 │    └─ 环节 Section（可删除/调序，不可手动新增/改内容）
 ├─ 环节 Section
 │    ├─ type: slide | quiz | demo
 │    ├─ 知识点列表（该环节对应的知识点）
 │    ├─ 生成状态: pending | generating | done
 │    ├─ 提示（预设选项，可选）
 │    └─ content（按 type 不同）
 ├─ 学习进度: 每用户每课程 { 未学习 | 正在学习 | 已完成 }
 └─ 问答会话 Conversation（归属 course_id + user_id，每用户每课程一条）
      └─ 消息 Message
           ├─ role: user | assistant
           ├─ content（文本，流式生成）
           ├─ sectionId（提问来源环节，可空）
           └─ createdAt（持久化）
```

### 3.1 Slide 讲解环节

```
Slide = 一页 Slide + N 个讲解步骤
  步骤 = { 讲解语句(text) + 动作(action) }
  动作 = { type: underline | highlight | box, targetElementId }
  页面元素 = { id, type: text | formula | shape | list, 内容 }
            · formula 用 KaTeX 渲染
  推进方式：手动「下一步」，可回退
  显示方式：逐字显示 + 可选 TTS 朗读（默认关闭）
```

动作类型早期版本锁定三种：划线（underline）、高亮（highlight）、框选（box）。动作通过元素 ID 引用页面元素。

### 3.2 测试题环节

```
Quiz = 题目列表
  题目 = { 题干, 选项[], 正确答案[], 每选项解析[], type: single | multiple }
  交互：一次性作答 → 一次性展示全部答案 + 逐项题解
  判定：单选对/错；多选全对=对、部分对=半对
  不记录得分
```

每个选项都有解析。

### 3.3 互动演示环节

```
Demo = { subtype + 代码 }
  subtype: 3d | function | basic
  · 3d / function：固定代码框架（预注入 Three.js / 绘图库），智能体只补充逻辑
  · basic：纯 HTML5 / Canvas / SVG / CSS，禁止网络、禁止外部 JS 库
  · 唯一可编辑环节：人工编辑代码后保存
```

互动演示为独立环节类型，与 Slide 环节并列，不嵌套。

### 3.4 环节问答（智能体老师）

```
问答会话 Conversation（归属 course_id + user_id，课程级，跨环节共享）
 └─ 消息 Message
      ├─ role: user | assistant
      ├─ content（文本，流式生成）
      ├─ sectionId（提问来源环节，可空）
      └─ createdAt（持久化保存）
```

- 课程级一条独立会话，跨环节共享；老师结合整门课程上下文（各环节 Slide 内容 / 知识点 / 完整对话历史）作答，理解用户困惑点
- 对话历史持久化保存，退出后重进可回看，支持复习与持续追问
- 回答流式输出（SSE）
- 测试题环节：老师不泄露答案与题解，仅提示引导思考
- 问答可用时机：对应环节内容生成完成后（`done` 状态）可提问

## 4. 核心流程

1. **创建课程**：输入知识点 + 上传参考文档（PDF / Word / Markdown / 纯文本，10MB 上限，早期仅纯文本提取）
2. **生成大纲**：智能体生成环节列表 + 每环节形式 + 每环节重要知识点 → 用户确认（可删除/调序环节）
3. **后台串行生成**：确认后逐环节自动生成（保证连贯性，如「上一节我们学习了…」），用户只能看到已生成部分，经 SSE 推送进度
4. **学习交互**：Slide 手动播放、测试一次性作答、演示 iframe 交互
5. **环节问答**：任意环节下向智能体老师提问，流式回答，历史持久化
6. **课程管理**：私有 + 可分享到公共课程库；进度为课程级三态

## 5. 模型配置

- 支持国内外主流模型供应商，用户自选/自配
- API Key：服务端统一配置 + 用户可配置专属 Key
- TTS 与模型 API 一起配置，默认关闭
- 问答复用课程生成同一套模型配置，用户提问时可切换模型

## 6. 用户干预权（早期版本）

- ✅ 大纲：删除环节、调整顺序
- ✅ 为环节追加预设提示选项（非自由 prompt）
- ✅ 编辑互动演示代码（保存）
- ❌ 手动新增/修改大纲环节、修改 Slide / 讲解语句 / 测试题内容

## 7. 待定项（后续版本）

- 图片/公式/图表的文档解析
- 手动新增/修改大纲环节
- 已生成环节内容的手动编辑（除互动演示代码外）
