# 智能体课堂系统 · 数据库设计

> 版本 v1.0（已确认）

## 1. 通用约定

- 主键 `id`：`uuid`，使用 **UUIDV7**，由应用层（Go）生成（`uuid.NewV7()`）
- 时间戳：`timestamptz`
- `create_by / update_by`：`uuid NULL`，无创建人时留空，外键 → `users(id)`，`ON DELETE SET NULL`
- 无软删除（无 `deleted_at`）
- 审计字段按表差异化，见各表定义
- 用户专属模型 API Key：服务端对称加密（AES-256-GCM）后存储
- 环节详情（Slide 视觉内容与讲解步骤、demo 代码）与测试题选项/答案/解析以 `jsonb` 存储
- 参考文档提取文本**不落库**，仅在课程生成过程中临时使用

## 2. 枚举类型

```sql
CREATE TYPE course_status   AS ENUM ('draft', 'outline_confirmed', 'generating', 'completed');
CREATE TYPE section_type    AS ENUM ('slide', 'quiz', 'demo_3d', 'demo_function', 'demo_basic');
CREATE TYPE section_status  AS ENUM ('pending', 'generating', 'done');
CREATE TYPE question_type   AS ENUM ('single', 'multiple');
CREATE TYPE message_role    AS ENUM ('user', 'assistant', 'tool');
CREATE TYPE progress_status AS ENUM ('unstarted', 'in_progress', 'completed');
```

demo 拆为三种独立环节类型 `demo_3d / demo_function / demo_basic`，各自维护生成流程、提示词与代码模板；
其差异（预注入 Three.js / 绘图库 / 纯 HTML）由 `section.type` 表达，`content` 不再存 subtype。
对早期已建的库（`section_type` 仅含 `demo`），`Migrate` 会幂等为枚举补充三个新值，无需数据迁移。

## 3. 表结构

### 3.1 users（用户）

| 字段 | 类型 | 约束 |
|---|---|---|
| id | uuid | PK |
| username | text | UNIQUE NOT NULL |
| email | text | UNIQUE NOT NULL |
| password_hash | text | NOT NULL（bcrypt）|
| create_by | uuid | NULL FK→users |
| create_at | timestamptz | NOT NULL |
| update_by | uuid | NULL FK→users |
| update_at | timestamptz | NOT NULL |

```sql
CREATE TABLE users (
    id            uuid PRIMARY KEY,
    username      text NOT NULL UNIQUE,
    email         text NOT NULL UNIQUE,
    password_hash text NOT NULL,
    create_by     uuid REFERENCES users(id) ON DELETE SET NULL,
    create_at     timestamptz NOT NULL DEFAULT now(),
    update_by     uuid REFERENCES users(id) ON DELETE SET NULL,
    update_at     timestamptz NOT NULL DEFAULT now()
);
```

### 3.2 user_model_config（用户模型配置）

| 字段 | 类型 | 约束 |
|---|---|---|
| id | uuid | PK |
| user_id | uuid | NOT NULL FK→users |
| provider | text | NOT NULL（字符串枚举 openai/deepseek/qwen…）|
| model | text | NOT NULL |
| base_url | text | NOT NULL |
| api_key_encrypted | text | NOT NULL（对称加密）|
| is_default | bool | NOT NULL DEFAULT false |
| create_by | uuid | NULL |
| create_at | timestamptz | NOT NULL |
| update_by | uuid | NULL |
| update_at | timestamptz | NOT NULL |

```sql
CREATE TABLE user_model_config (
    id                uuid PRIMARY KEY,
    user_id           uuid NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    provider          text NOT NULL,
    model             text NOT NULL,
    base_url          text NOT NULL,
    api_key_encrypted text NOT NULL,
    is_default        boolean NOT NULL DEFAULT false,
    create_by         uuid REFERENCES users(id) ON DELETE SET NULL,
    create_at         timestamptz NOT NULL DEFAULT now(),
    update_by         uuid REFERENCES users(id) ON DELETE SET NULL,
    update_at         timestamptz NOT NULL DEFAULT now()
);

CREATE INDEX idx_user_model_config_user ON user_model_config (user_id);
-- 每个用户最多一个默认模型
CREATE UNIQUE INDEX uniq_user_model_config_default
    ON user_model_config (user_id) WHERE is_default;
```

### 3.3 course（课程）

| 字段 | 类型 | 约束 |
|---|---|---|
| id | uuid | PK |
| owner_id | uuid | NOT NULL FK→users |
| title | text | NOT NULL |
| description | text | NOT NULL（知识点描述）|
| status | course_status | NOT NULL DEFAULT 'draft' |
| is_public | bool | NOT NULL DEFAULT false |
| create_by | uuid | NULL |
| create_at | timestamptz | NOT NULL |
| update_at | timestamptz | NOT NULL（仅 status / is_public 变更）|

```sql
CREATE TABLE course (
    id          uuid PRIMARY KEY,
    owner_id    uuid NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    title       text NOT NULL,
    description text NOT NULL,
    status      course_status NOT NULL DEFAULT 'draft',
    is_public   boolean NOT NULL DEFAULT false,
    create_by   uuid REFERENCES users(id) ON DELETE SET NULL,
    create_at   timestamptz NOT NULL DEFAULT now(),
    update_at   timestamptz NOT NULL DEFAULT now()
);

CREATE INDEX idx_course_owner ON course (owner_id);
```

### 3.4 outline（大纲 — 独立表，保存原始 JSON）

| 字段 | 类型 | 约束 |
|---|---|---|
| id | uuid | PK |
| course_id | uuid | NOT NULL FK→course |
| content | jsonb | NOT NULL（原始大纲 JSON）|
| status | text | NOT NULL DEFAULT 'draft'（draft / confirmed）|
| create_by | uuid | NULL |
| create_at | timestamptz | NOT NULL |
| update_by | uuid | NULL |
| update_at | timestamptz | NOT NULL |

```sql
CREATE TABLE outline (
    id        uuid PRIMARY KEY,
    course_id uuid NOT NULL REFERENCES course(id) ON DELETE CASCADE,
    content   jsonb NOT NULL,
    status    text NOT NULL DEFAULT 'draft',
    create_by uuid REFERENCES users(id) ON DELETE SET NULL,
    create_at timestamptz NOT NULL DEFAULT now(),
    update_by uuid REFERENCES users(id) ON DELETE SET NULL,
    update_at timestamptz NOT NULL DEFAULT now()
);

CREATE INDEX idx_outline_course ON outline (course_id);
```

### 3.5 section（环节）

| 字段 | 类型 | 约束 |
|---|---|---|
| id | uuid | PK |
| course_id | uuid | NOT NULL FK→course |
| position | int | NOT NULL（顺序）|
| type | section_type | NOT NULL |
| knowledge_points | jsonb | NOT NULL（环节知识点列表）|
| prompt | text | NULL（预设提示选项）|
| status | section_status | NOT NULL DEFAULT 'pending' |
| content | jsonb | NULL（按 type：slide 视觉内容 / demo 代码）|
| steps | jsonb | NULL（slide 讲解步骤，仅 slide 使用）|
| create_by | uuid | NULL |
| create_at | timestamptz | NOT NULL |
| update_by | uuid | NULL |
| update_at | timestamptz | NOT NULL |

```sql
CREATE TABLE section (
    id               uuid PRIMARY KEY,
    course_id        uuid NOT NULL REFERENCES course(id) ON DELETE CASCADE,
    position         integer NOT NULL,
    type             section_type NOT NULL,
    knowledge_points jsonb NOT NULL DEFAULT '[]',
    prompt           text,
    status           section_status NOT NULL DEFAULT 'pending',
    content          jsonb,
    steps            jsonb,
    create_by        uuid REFERENCES users(id) ON DELETE SET NULL,
    create_at        timestamptz NOT NULL DEFAULT now(),
    update_by        uuid REFERENCES users(id) ON DELETE SET NULL,
    update_at        timestamptz NOT NULL DEFAULT now()
);

CREATE UNIQUE INDEX uniq_section_course_position ON section (course_id, position);
```

### 3.6 question（测试题 — 独立表）

| 字段 | 类型 | 约束 |
|---|---|---|
| id | uuid | PK |
| section_id | uuid | NOT NULL FK→section |
| position | int | NOT NULL |
| type | question_type | NOT NULL |
| stem | text | NOT NULL（题干）|
| options | jsonb | NOT NULL（选项数组）|
| answers | jsonb | NOT NULL（正确选项索引数组）|
| explanations | jsonb | NOT NULL（每选项解析数组）|
| create_by | uuid | NULL |
| create_at | timestamptz | NOT NULL |
| update_by | uuid | NULL |
| update_at | timestamptz | NOT NULL |

```sql
CREATE TABLE question (
    id           uuid PRIMARY KEY,
    section_id   uuid NOT NULL REFERENCES section(id) ON DELETE CASCADE,
    position     integer NOT NULL,
    type         question_type NOT NULL,
    stem         text NOT NULL,
    options      jsonb NOT NULL,
    answers      jsonb NOT NULL,
    explanations jsonb NOT NULL,
    create_by    uuid REFERENCES users(id) ON DELETE SET NULL,
    create_at    timestamptz NOT NULL DEFAULT now(),
    update_by    uuid REFERENCES users(id) ON DELETE SET NULL,
    update_at    timestamptz NOT NULL DEFAULT now()
);

CREATE UNIQUE INDEX uniq_question_section_position ON question (section_id, position);
```

### 3.8 conversation（用户课程下的问答会话）

| 字段 | 类型 | 约束 |
|---|---|---|
| id | uuid | PK |
| course_id | uuid | NOT NULL FK→course |
| user_id | uuid | NOT NULL FK→users |
| title | varchar(16) | NOT NULL DEFAULT ''（首问时以提问前 10 个字符写入，仅首问生效）|
| create_by | uuid | NULL |
| create_at | timestamptz | NOT NULL |
| update_at | timestamptz | NOT NULL（最后消息时间，列表按其倒序）|

```sql
CREATE TABLE conversation (
    id        uuid PRIMARY KEY,
    course_id uuid NOT NULL REFERENCES course(id) ON DELETE CASCADE,
    user_id   uuid NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    title     varchar(16) NOT NULL DEFAULT '',
    create_by uuid REFERENCES users(id) ON DELETE SET NULL,
    create_at timestamptz NOT NULL DEFAULT now(),
    update_at timestamptz NOT NULL DEFAULT now()
);

CREATE INDEX idx_conversation_course_user_updated ON conversation (course_id, user_id, update_at DESC);
```

多会话支持：每用户每课程可建多条会话；旧库的
`uniq_conversation_course_user` 唯一索引由 `Migrate` 幂等移除，`title` 列幂等补充。

### 3.9 message（消息 — 仅 created_at）

讨论模式（智能体老师）的对话消息。`content` 为 jsonb：按 role 结构化存储——
`user`/`assistant` 文本轮为 `{"text": ...}`；`assistant` 工具调用轮为
`{"tool_calls":[{"id","name","arguments"}...]}`；`tool` 为
`{"tool_call_id","name","result"}`（后端合成的 "success"）。
旧库中 `message_role` 仅含 user/assistant，`Migrate` 幂等补 `tool` 值。

| 字段 | 类型 | 约束 |
|---|---|---|
| id | uuid | PK |
| conversation_id | uuid | NOT NULL FK→conversation |
| role | message_role | NOT NULL |
| content | jsonb | NOT NULL |
| section_id | uuid | NULL FK→section（提问来源环节，仅 user 消息携带）|
| created_at | timestamptz | NOT NULL |

```sql
CREATE TABLE message (
    id              uuid PRIMARY KEY,
    conversation_id uuid NOT NULL REFERENCES conversation(id) ON DELETE CASCADE,
    role            message_role NOT NULL,
    content         jsonb NOT NULL,
    section_id      uuid REFERENCES section(id) ON DELETE SET NULL,
    created_at      timestamptz NOT NULL DEFAULT now()
);

CREATE INDEX idx_message_conversation_created ON message (conversation_id, created_at);
```

### 3.10 progress（学习进度 — user + course 关联）

| 字段 | 类型 | 约束 |
|---|---|---|
| id | uuid | PK |
| course_id | uuid | NOT NULL FK→course |
| user_id | uuid | NOT NULL FK→users |
| status | progress_status | NOT NULL DEFAULT 'unstarted' |
| create_at | timestamptz | NOT NULL |
| update_at | timestamptz | NOT NULL |

```sql
CREATE TABLE progress (
    id        uuid PRIMARY KEY,
    course_id uuid NOT NULL REFERENCES course(id) ON DELETE CASCADE,
    user_id   uuid NOT NULL REFERENCES users(id) ON DELETE CASCADE,

    create_at timestamptz NOT NULL DEFAULT now(),
    update_at timestamptz NOT NULL DEFAULT now()

CREATE UNIQUE INDEX uniq_progress_course_user ON progress (course_id, user_id);
```

## 4. 关系与约束汇总

| 关系 | 关联方式 |
|---|---|
| course → users（owner）| owner_id FK |
| outline / section / document → course | course_id FK，CASCADE |
| question → section | section_id FK，CASCADE |
| conversation → (course, user) | course_id/user_id FK，CASCADE；多会话（无复合唯一）|
| message → conversation | conversation_id FK，CASCADE；section_id SET NULL |
| progress → (course, user) | 复合唯一约束，CASCADE |
| user_model_config → users | user_id FK，CASCADE |

## 5. 存储说明

- **Slide 环节** 分两列存储，支撑「先生成元素、再参考元素生成讲解」的两阶段生成（完整 schema 见 `docs/slide数据结构.md`）：
  - `section.content`（jsonb）— 视觉内容（画布 + 元素）：
    ```json
    {
      "width": 1280, "height": 720,
      "background": "#ffffff", "accent": "#14b8a6",
      "elements": [
        { "id": "e1", "type": "text", "x": 80, "y": 60, "width": 1120,
          "content": "标题", "style": { "fontSize": 40, "align": "left", "bold": true } },
        { "id": "e2", "type": "formula", "x": 80, "y": 220, "content": "E=mc^2", "fontSize": 32 }
      ]
    }
    ```
  - `section.steps`（jsonb）— 讲解步骤（仅 slide 使用）：
    ```json
    [
      { "text": "讲解语句", "actions": [{ "type": "highlight", "targetElementId": "e1" }] }
    ]
    ```
- **demo 环节** `section.content`（jsonb）：后端用类型专属模板拼接后的完整可运行 HTML 代码
  （`demo_3d`/`demo_function` 在骨架预注入运行库，`demo_basic` 为纯 HTML），大模型只产出逻辑片段：
  ```json
  { "code": "…完整 HTML…" }
  ```
- **测试题** `options / answers / explanations` 各为独立 jsonb 数组，`answers` 存正确选项下标
- 参考文档提取文本不入库，仅生成流程内存/临时文件使用
