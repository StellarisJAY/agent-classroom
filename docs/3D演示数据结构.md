# 3D 演示数据结构（demo_3d）

## 概述

`demo_3d` 环节由 LLM 产出一个**纯数据 JSON**（无任何可执行代码），落库到 `section.content`，
前端在主应用内导入 Three.js 渲染为可交互 3D 场景（不经 iframe 沙箱，`demo_function`/`demo_basic`
不受影响）。

核心思想：**场景出自 LLM 的只有声明式描述**——几何体、材质、灯光、相机、控制器五类集合；
场景初始化、渲染循环、控制器实现全部由系统封装，智能体只做参数化引用。

```
+---------------------------+
| LLM 产出 JSON（纯数据）    |
+---------------------------+
            | ExtractJSON + 校验（重试）
            v
   section.content (jsonb)
            |
            v
+---------------------------+
| 前端 schema 修剪 + 渲染器   |  three npm 包，主应用内渲染
+---------------------------+
```

## 内容 JSON 结构

顶层为五个集合（`scene` 可选，其余必备，允许空数组）：

```json
{
  "scene": { "background": "#0f172a", "axesHelper": true },
  "geometries": [ /* 几何体，见下 */ ],
  "materials":  [ /* 材质，见下 */ ],
  "lights":     [ /* 灯光，见下 */ ],
  "cameras":    [ /* 相机，见下 */ ],
  "controls":   [ /* 控制器，见下 */ ]
}
```

### scene

| 字段 | 类型 | 约束 | 默认（缺省时） |
|---|---|---|---|
| background | 颜色字符串 | 合法 hex（`#rgb`/`#rrggbb`） | `#0f172a` |
| axesHelper | boolean | - | false |

### geometries（几何体集合，≤ 20 个）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | string | 非空、场景内唯一 | 被 materialId / controls.targetId 引用 |
| type | 枚举 | 未知 → **丢弃该元素** | 下方 primitive 清单 |
| args | number[] | 按 type 定长（见参数表）；缺失/非法按类型默认值 | primitive 构造参数 |
| position | [x,y,z] | 每个 ≤ 1e4 | 世界坐标，默认 `[0,0,0]` |
| rotation | [x,y,z] | 弧度，每个 \|v\| ≤ 2π | 欧拉角，默认 `[0,0,0]` |
| scale | number 或 [x,y,z] | **必须 > 0**；统一值或三轴 | 默认 1 |
| materialId | string | 悬空引用 → **兜底默认材质** | 材质 id |

primitive 清单与 args（单位约定）：

| type | args | 说明 |
|---|---|---|
| Box | [w, h, d] | 三边长 |
| Sphere | [radius, widthSegments, heightSegments] | 分段默认 32/16 |
| Cylinder | [radiusTop, radiusBottom, height, radialSegments] | |
| Cone | [radius, height, radialSegments] | |
| Torus | [radius, tube, radialSegments, tubularSegments] | |
| TorusKnot | [radius, tube, tubularSegments, radialSegments] | |
| Plane | [w, h] | 默认 xz 平面朝上（旋转 -π/2 由 LLM 自行用 rotation 表达）|
| Icosahedron | [radius, detail] | |

### materials（材质集合，≤ 20 个）

| 字段 | 类型 | 约束 | 默认 |
|---|---|---|---|
| id | string | 非空、唯一 | - |
| type | 枚举 | 未知 → 兜底 `MeshStandardMaterial` | MeshStandardMaterial |
| color | hex | | 材质各自默认色 |
| roughness | number | [0,1] | 0.5 |
| metalness | number | [0,1] | 0.0 |
| opacity | number | [0,1]；<1 时自动启用透明 | 1.0 |
| emissive | hex | 仅 Phong/Standard/Physical 生效 | 黑（无自发光）|

type 枚举：`MeshStandardMaterial`、`MeshBasicMaterial`、`MeshLambertMaterial`、
`MeshPhongMaterial`、`MeshPhysicalMaterial`、`MeshNormalMaterial`。

`roughness`/`metalness` 仅对 Standard/Physical 类材质生效；`MeshBasicMaterial` 不受灯光影响。

### lights（灯光集合，≤ 3 个）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| type | 枚举 | 未知 → 丢弃该元素 | 下方清单 |
| color | hex | | |
| intensity | number | ≥ 0 | |
| position | [x,y,z] | | 灯光位置 |
| target | [x,y,z] | 仅指向型灯光 | 见下 |
| castShadow | boolean | | 期望开阴影时为 true（渲染器按成本兜底，见「兜底矩阵」）|

type 枚举与方向语义：

| type | 有方向语义？ | 方向表达 |
|---|---|---|
| AmbientLight | 无（全向环境光） | 无需方向 |
| HemisphereLight | 无（天空/地面双色） | 无需方向 |
| DirectionalLight | **有** | 从 `position` 指向 `target`（默认 `[0,0,0]`）；需通过 field 移动 position 或调整 target 来改变照射方向 |
| PointLight | 无（各向同性衰减光源） | 无需方向 |
| SpotLight | **有** | 从 `position` 指向 `target`，形成锥形光斑 |

即：灯光用「position + target」表达朝向（等价于 Three.js 内部的灯光 target 对象旋转），
不引入 rotation 字段，避免与 position 叠加歧义。

### cameras（相机集合，**有且仅 1 个**）

| 字段 | 类型 | 约束 | 默认 |
|---|---|---|---|
| type | 枚举 | 其他值 → 整个数组置为默认透视相机 | PerspectiveCamera |
| position | [x,y,z] | | `[5,5,5]` |
| fov | number | (0,180]（仅透视） | 50 |
| lookAt | [x,y,z] | | 原点 |

type 枚举：`PerspectiveCamera`、`OrthographicCamera`。数组可能含多个但渲染器**只取第一个**（第一期 LLM 侧也约束只生成 1 个）。

### controls（控制器集合，数量不限，每个组件绑定一个目标）

由系统统一封装实现，LLM 只做参数化引用，**不允许任何自定义逻辑/回调**。
命名对齐 3D 图形学三种基础变换；交互模型为**滑块直接控制绝对变换值**（无需每帧积分，
控制器零状态），动态感由用户拖动滑块的连续变化天然提供。
`speed`/`value` 字段整体废弃——物体的初始位置/朝向由 `geometries` 的
`position`/`rotation` 初值表达，控制器操控的是该轴**绝对值**：

| type | 目标 | 语义 | 滑块值域（系统固定，LLM 不指定）|
|---|---|---|---|
| orbit | 相机 id 或省略指向唯一相机 | 拖拽环绕相机 + 滚轮缩放距离 | -（OrbitControls）|
| rotation | mesh id | 直接设置该 mesh 绕 axis 的**绝对欧拉角** | [-180°, 180°]，初始为该 mesh 当前 rotation |
| translation | mesh id | 直接设置该 mesh 沿 axis 的**绝对世界坐标** | [-50, 50]（世界单位），初始为当前 position |
| scale | mesh id | 直接设置该 mesh 沿 axis 的**绝对缩放倍率**（基准尺寸 × 倍率）| (0, 5]，初始 1（不缩放）|

通用字段：

| 字段 | 类型 | 约束 | 默认 |
|---|---|---|---|
| type | 枚举（上表）| 无法解析的 type → 丢弃该控制器 | - |
| title | string | 控制器在前端滑块面板的显示名称 | 按类型生成默认文案 |
| targetId | string | 相机 id 或 mesh id；悬空 → 丢弃该控制器 | orbit 类型可省略（绑定唯一相机）|
| axis | `x`/`y`/`z` | rotation 默认 `y` | y |

可选字段：

| 字段 | 适用类型 | 说明 |
|---|---|---|
| autoRotate | orbit | 布尔。意图为开启拖拽自转；**当前版本仅声明与存储，前端不实现自转计算**（字段保留，后续版本生效）|

scale 控制的滑块值域 (0, 5] 为系统固定区间；LLM/输入数值越界时取边界值并 console.warn。

## 校验策略（职责分工）

**后端（生成期，决定是否重试）**：

- `ExtractJSON` 解析失败、顶层缺失任意必备集合、计数超限（mesh > 20 / lights > 3）→ 解析/校验失败，走 `util.Retry`（同 demo_basic，共 2 次尝试）。
- 未知 geometry/light/材质 type、材质类型未知等 → **不在后端重试**，由前端兜底（避免整次重推浪费 token）。

**前端（渲染期兜底矩阵）**：

| 异常 | 处理 |
|---|---|
| geometry/light type 未知 | 丢弃该元素 |
| materialId 悬空 | 兜底默认材质（MeshStandardMaterial，中性色）|
| 材质 type 未知 | 兜底 MeshStandardMaterial |
| cameras 为空 / type 未知 | 默认透视相机 `[5,5,5]` fov 50 |
| controls targetId 悬空 / type 未知 | 丢弃该控制器 |
| scale / 缩放 value ≤ 0 | 取默认值 1 并 console.warn |
| 数值字段非法 | 用字段默认值 |

## 与大纲生成阶段的关系

3D 演示分两阶段收敛：**大纲阶段定「内容」、内容生成阶段定「实现」**。

- 大纲阶段（`prompts/outline.md` 的 `demo_3d` description 规则）：
  - 只描述**场景内容**——有哪些物体、大致形态与相对位置/组合关系、要传达的核心效果；
    不必指定具体几何体（例：“水分子：两个小的氢原子和一个较大的氧原子构成 V 形”）。
  - 告知智能体可用原型有限（Cube/Sphere/Cylinder/Cone/Torus/TorusKnot/Plane/Icosahedron、无外部
    模型导入），使其意识到场景必须是**少数简单几何体的组合示意**，回避复杂精细模型（人物、机械等）。
  - **不提及**灯光、材质、相机视角、控制器——统一由内容生成阶段的系统提示词按规则决定。
- 内容生成阶段（`prompts/demo_3d.md`）：在这段大纲描述之上产出完整的五集合 JSON。

## 提示词要点（prompts/demo_3d.md）

- 行为边界：只允许产出五集合 JSON，禁止书写任何 JS/HTML 代码；场景初始化、渲染循环、控制器实现由系统提供。
- 内置组件用法：完整列出 primitive/材质/灯光/相机/控制器的参数表与单位约定（同上文）；控制器只声明 type/targetId/axis（及 orbit 的 autoRotate 标志），滑块值域由系统固定，LLM 不得指定数值范围或初值（初值只经 geometries 的 position/rotation/scale 表达）。
- 设计守则：优先用少量内置简单几何体组合表达概念（形体拼装优于复杂参数）；灯光至少一盏满足标准材质照明（建议环境光 + 指向型主灯）；材质颜色应具辨识度、避免全场同色；背景选中性色避免与主体冲突。
- few-shot：附一个完整的正确输出示例 JSON。
- token 消耗优先级最低，输出稳定性优先。

## 渲染器行为（前端约定）

- 组件：`web/src/components/learn/demo3d/`（`types.ts` 契约类型 / 修剪逻辑、`Demo3DScene.ts` 纯函数式场景构建器、`Demo3DRenderer.vue` 壳）；Three.js 经 npm 引入主应用。
- 初始化：renderer、scene、唯一相机由系统完成；背景色 / 坐标轴辅助线由 scene 字段决定。
- 控制器映射：orbit → `OrbitControls`；rotation/translation/scale → 系统封装的模型变换滑块——abs 值直接赋给 `mesh.rotation/position/scale[axis]`，无需每帧积分；多个 controls 可并存，各控制一个目标轴。
- 生命周期：`ResizeObserver` 自适应容器；组件卸载时 `dispose()` 释放几何体/材质/renderer。
- 解析失败（JSON 严重结构非法）→ 壳组件渲染降级提示，不抛出。
